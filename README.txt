BRAINBYTE SOLUTIONS - STREAMLIT APP

Included:
- app.py
- assets folder (brand logo and banner images)
- requirements.txt

Run locally:
1. Install Python
2. Open CMD inside this folder
3. Run: pip install -r requirements.txt
4. Run: streamlit run app.py

Deploy:
1. Upload this folder's files to a GitHub repository.
2. On Streamlit Community Cloud, create a new app and choose that repository.
3. Set app file path to app.py
4. Deploy.

Tools:
- Home dashboard
- LinkedIn Optimization Checklist
- Dataset Lab (CSV/Excel upload, preview, missing-value report, descriptive stats, charts, export)
- Content Studio draft builder
- Profile checklist score
- Resources downloads

Privacy: Dataset processing is done in this app session. Avoid uploading confidential/personal datasets to public deployments.
