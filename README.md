# BrainByte Solutions — Streamlit Workspace

## Deploy on Streamlit Community Cloud
1. Upload this folder to a GitHub repository.
2. Open Streamlit Community Cloud and choose **New app**.
3. Select your repository and `app.py` as the main file.
4. Deploy.

## Files
- `app.py`: main application
- `requirements.txt`: dependencies
- `brainbyte_logo.jpeg`: BrainByte branding image
- `sample_dataset.csv`: small demo dataset (optional)

This app includes a LinkedIn Toolkit, CSV Dataset Lab, and a Resources & Files workspace.
